## What S1 is

Network `nasctime.simulations.m1.M1Bridge` with `[Config S1]` is a copy of Simu5G 1.8.0's `EthernetSessions` network as used by its `Ethernet-Bridge` config:
- `talker`: the VLAN-tagging Ethernet device behind the UE.
- `ue[0]`: Ethernet PDU session, bridge mode.
- `gnb1`.
- `upf`: Ethernet session bridge.
- `listener`: the station on the N6 Ethernet LAN.
- PCP 5 → QFI 5 → DRB 2; PCP 0 → default QFI → DRB 1, in both directions.

Only the station names differ (`device[0]` → `talker`, `dnStation` → `listener`). Submodule order and parameters are unchanged. The unused `server` and `router` are kept so that addresses and random-number use stay identical.

**Run method:** `opp_run -l simu5g` with NED path `<nascTime>/simulations : <Simu5G>/src : <INET>/src`. Including nascTime's legacy `simulations/` NED files does not break loading.
