## 2. RC-2: the concrete DL scheduler, and why `rtxAcid` is absent (CONFIRMED; VM-consistent)

## 3. Resolving mixed groups from gNB evidence (CONFIRMED rules)

A unit key is (node, p, cw): one TX buffer per UE (`HarqTxBuffers`, `LteMacBase.h:36`). After a feedback group G:
- a **NACKed** unit is BUFFERED. Its next event on its key can only be the retransmission:
  - `selected for retransmission` for process p in a later main loop;
  - then the extract of **its own MAC id**.

  An insert into a non-empty unit throws (`LteHarqBufferTx.cc:122-123`).
- an **ACKed or discarded** unit is EMPTY. Its next event on the key can only be a **new insert**.

Each candidate's first subsequent key event classifies it as **rtx-proven** or **emptied**. Counts close a group as soon as the number of rtx-proven candidates equals the number of `set for RTX` lines.

Discard versus ACK among the emptied units is decided by:
1. a handle bound to the lifecycle (§4);
2. eligibility: only ntx = maxHarqRtx + 1 can be discarded; if the number of eligible units equals the number of DISC lines, they are the discards;
3. otherwise **UNRESOLVED** (fail-closed).

## 4. Handles bound to PDU lifecycles (revision point 3)

### 4.1 Objects

- **Lifecycle** L = (MAC id, node, p, cw, t_ins). It starts at the gNB insert line and ends at its terminal event: ACK resolved, discard resolved, or structural censoring (§7).
- **Unit keys** (node, p, cw) are reusable and are **never** used as handle keys.
- **Handle** H: the cMessage id from an RTX / DISC line.

The state per H is **unbound**, **bound(L)**, **ambiguous(set of L)** or **retired(L)**.

### 4.2 Rules

All violations are **A2-1 FAIL**, recorded with both identifiers and both line positions.

| Rule | Content |
|---|---|
| B-1 **bind** | bind H to L only when the line is uniquely L's: a single-candidate group; or a resolved group with exactly one RTX/DISC line and one matching lifecycle. Never by key, never by numerical relation. |
| B-2 **use** | a bound H may appear only in a group in which L is a WAIT candidate. Otherwise "bound handle outside the candidates". |
| B-3 **one handle per lifecycle** | if L already has H and another H′ is identified as L's → "handle changed within a lifecycle". This contradicts `pdu_` constancy (§1). |
| B-4 **retirement** | when L ends, H is retired. Any later appearance of a retired H → "retired handle reused". |
| B-5 **collision** | an H first seen on a line must not be bound to, ambiguous with, or retired from another lifecycle. |
| B-6 **no reuse across lifecycles** | a new lifecycle on the same key always starts unbound, even if its predecessor's H was known. |

**Basis for B-4 / B-5.** `messageId = nextMessageId++` (`cmessage.cc:44, 60`). The only id-reusing path, `privateDup` (`:240-248`), is called only by Qtenv (`qtenv/logbuffer.cc`). The run uses Cmdenv. So reuse in a valid run is impossible, and a collision indicates a defect.

### 4.3 Simultaneous multi-NACK groups (revision point 4)

A group with m ≥ 2 RTX lines whose rtx-proven lifecycles are {L1…Lm}:
- **Per-line ownership** is recorded as the **set** {L1…Lm} for every one of these lines. Per-UE NACK counts are exact as a multiset (each L got one NACK). Occupancy is exact: all stay busy.
- **Handles:** each Hi becomes **ambiguous({L1…Lm})**. No pairing is chosen.
- **Narrowing by elimination only:** if a later group shows Hi on a line whose candidate set intersects the ambiguity set in exactly one Lj, then Hi binds to Lj, and Lj is removed from the other handles' sets. This repeats until nothing changes. A set that becomes empty → A2-1 FAIL.
- A later **discard** that needs an ambiguous H, and that the ntx eligibility rule (§3) cannot resolve → **UNRESOLVED** (A2-1 FAIL).
- Records report every ambiguous relation that remains at the end. The coverage row counts "multi-NACK groups: relations left exchangeable". **No unique assignment is ever claimed.**

## 6. Deferred resolution: state and occupancy at the original events (revision point 5)

- **Recording.** Every gNB line keeps its original index `gi` and time `t`.
  - A PENDING group stores its lines (gi, t) and its candidate lifecycles. These enter state PEND, which is provisional and busy: the unit is non-empty for either outcome until the group's line.
  - PEND units are not candidates of later groups.
- **Resolution** (first key event per candidate, §3) applies the transitions **as of the group's lines**:
  - **emptied L:** `end = ack | discard`, `t_close = t_G`, `close_gi` = the gi of its assigned line. For exchangeable ACKs: the group's line positions in the existing certified order.
  - **rtx-proven L:** WAIT → BUF at the gi / t of its RTX line (`nack_t = t_G`). The resolving extract then applies BUF → WAIT at its own gi / t (ntx + 1).
- **Occupancy.** It is computed only after the replay, from the busy events sorted by gi (`P.occupancy_log_order`, unchanged), so retroactive close events land at the true positions.
- **Feedback ages** are computed at the group time from `last_tx` (known at G), as now.
- **Invariant** (test T-defer-equiv). The final per-lifecycle history (transitions with gi / t) and the per-UE occupancy series equal those of a non-deferred replay given the true assignment (generator truth).

## 7. Fail-closed censoring without empirical bounds (revision point 6)

**Opportunity.** The gNB main loop logs `-----ENB MAIN LOOP -----` / `--- END ENB MAIN LOOP ---` under `mac` (`LteMacEnb.cc:767, 841`; component `mac`, level info). A-2.1 adds these two texts to its line filter. They do not affect ACK-only rows (T-ackonly). A complete main loop **after** an event, in log order, is a resolution opportunity: a retransmission, insert or feedback could have been logged.

| End-of-log situation | Classification | Effect |
|---|---|---|
| WAIT, no feedback yet, and the next feedback time (last_tx + d*) is after t_end | **censored: awaiting feedback** (structural: d* is the run's single feedback age, gated by A2-3) | as now |
| BUF (a NACK applied, no retransmission yet) with **no complete main loop after the NACK line** | **censored: awaiting retransmission** (structural) | allowed |
| BUF with ≥ 1 complete main loop after the NACK, still no retransmission | **UNRESOLVED: retransmission not observed**. Simu5G may legitimately defer (e.g. no RBs), and the scheduler's reason is not logged (§2). | A-2.1 verdict **INCOMPLETE**, never PASS. A2-8 is NOT EVALUATED for that UE. |
| PENDING group with no complete main loop after its last line | **censored: awaiting resolution** (structural) | lines excluded from the per-UE counts. A2-8 NOT EVALUATED for the affected UE(s). Verdict **INCOMPLETE**. |
| PENDING group with ≥ 1 complete main loop after it, unresolved | **UNRESOLVED** | **INCOMPLETE** |
| INS in the last TTI | censored (as now) | — |

**Effect on A2-V1.** A2-V1 requires A2-8 PASS and A-2 VALID, so every non-structural case keeps it **NOT ACCEPTED**: fail-closed.

**The frozen A-2.** Its window `rtx_wait = max(1 ms, observed delays)` (`m2s72_a2.py`, end of `replay`) is an empirical bound. It is **not** reused in A-2.1, and it is recorded as a limitation of the frozen version.
