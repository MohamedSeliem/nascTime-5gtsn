## 2. The state machine as implemented (design §5, with the refinements of §3)

The machine works on the gNB lines only, per unit (UE node, process, codeword).

| Line | Effect | Fails |
|---|---|---|
| insert(X, n) | unit := INSERTED, busy +1 for n | A2-2 if the unit is occupied or X is a duplicate |
| extracted(X, n) | INSERTED/BUFFERED → WAITING, last_tx, n_tx + 1 | A2-2 if X is not in the unit, the first transmission is outside the insert TTI, or the unit is WAITING. A2-4 if a retransmission lacks DL `rtxAcid … User[n] … ACID [p]` and "selected for retransmission" in its TTI |
| feedback event (start, one unit outcome, feedback line) | the line joins the group (t, p, c). Candidates are the WAITING units on (p, c) of largest age | A2-1 if malformed or without candidate |
| group resolution | NACK / discard by the PDU id of its unit line ("id"), then ACKs: 1 : 1 "single", k : k "exchangeable". NACK → BUFFERED (stays busy); discard and ACK → unit emptied, busy −1 | A2-1 on an unidentified NACK or a count mismatch. A2-2 on a discard at n_tx ≠ maxHarqRtx + 1 (maxHarqRtx read from the discard text itself) |
| end of log | WAITING with last_tx + d* > t_end → *censored: awaiting feedback*. INSERTED in the last TTI → *censored: inserted in the last TTI*. BUFFERED with t_end − NACK ≤ max(1 TTI, the longest NACK→retransmission delay of the run) → *censored: awaiting retransmission* | A2-2 for anything else still open |

**d*_tx** must be one value (A2-3). **t_end** is the log's last time stamp over all modules; the sentinel line carries it.

## 3. Implementation vs design: deviations and refinements (each with its reason and its test)

| # | Change | Reason | Test / mutation |
|---|---|---|---|
| R-1 | standalone CLI `check_m2s72_a2.py` instead of new subcommands in `check_m2s72_s5n2.py` (design §8 item 2) | keeps the tool of the accepted N = 2 smoke byte-identical | T-scope |
| R-2 | a group is resolved when time advances **or** a main-loop insert / transmission touches **one of its candidate units**, not on every main-loop event | at N ≥ 3 an uninvolved UE's event inside a same-instant feedback burst would otherwise be a false certificate alarm | T-cert; mutation M12 |
| R-3 | the certificate is explicit: no insert (the only +1 occupancy step) of a candidate **node** strictly between the group's first and last line; plus split detection (a line of an already resolved group) | R-2 alone would miss an insert of a candidate node on another process. The design's "no event of a candidate node" is tightened to the events that can change occupancy | T-cert, NC-A2-cert; mutations M6, M11 |
| R-4 | A2-7's reference occupancy closes a PDU at its last feedback only if that feedback ends it (ACK, or a NACK the gNB logged as a discard) | XA's "last observed feedback" would close a PDU that is NACKed and awaiting retransmission at the end of the log; A-2 (and Simu5G) keep it busy | T-censor, T-xa |
| R-5 | A2-0s is its own row | the source contract must be visible on the VM; NOT EVALUATED without a tree, which makes the verdict INCOMPLETE | T-contract |
| R-6 | status NOT EXERCISED (distinct from PASS and NOT EVALUATED) for A2-4 / A2-5 when the run has no retransmission / group | the run must never claim what it did not contain | T-verdict |
| R-7 | not implemented: the eventlog owner reader (design §8 item 4) | the eventlog covers 0–0.5 s only; deferred, recorded as a limitation | — |

- **NOT VALID** (rc 1): any FAIL.

|---|---|---|

| discard after max retransmissions; mixed ACK / NACK groups | **not exercised** | **synthetic only** (T-sweep, T-nack, T-discard) |

**The three classes you asked for:**
1. **Validated with real output:** single and two-way exchangeable ACK attribution, d*_tx, unit life cycle without NACK, conservation, per-UE occupancy (two independent derivations agree), the Simu5G scalar cross-check.
2. **Validated only with synthetic evidence:**
   - generator fixtures: NACK identification, retransmission state, discard, mixed groups, groups of 3+, censoring of inserted / awaiting-retransmission units;
   - one source-faithful NACK chain injected into the real N = 2 log: NACK and retransmission in real context.
3. **Not yet evaluated:** any NACK, retransmission or discard **emitted by Simu5G itself** in a real run; real N ≥ 3; codeword 1; UL.

## 5. Controls (`a2-controls`, in memory; raw outputs only read)

Each control is reported as **AS DECLARED**, **NOT AS DECLARED** or **NOT BUILDABLE** (with the reason). NOT BUILDABLE never counts as a pass.

| Control | Kind | Declared |
|---|---|---|
| PC-A2-unmodified | real | every row status reproduced |
| NC-A2-shift | real | one single ACK's feedback event one TTI late → A2-3 FAIL |
| NC-A2-dupack | real | feedback event duplicated → A2-1 FAIL |
| NC-A2-dropfb | real | feedback event removed → A2-2 FAIL |
| NC-A2-dropunit | real | unit ACK line removed → A2-1 and A2-0 FAIL |
| NC-A2-extract | real | a transmission line removed → A2-1 or A2-2 FAIL |
| NC-A2-dupins | real | an insert duplicated → A2-2 FAIL |
| NC-A2-swap | real (N ≥ 2) | one PDU of the busiest UE logged for the other node → **A2-7 FAIL** (the independent reference sees what sums cannot) |
| NC-A2-xa | real (N ≥ 2) | the reference's own evidence corrupted → A2-7 FAIL |
| NC-A2-grant | real | one UE's grants removed in an insert TTI → A2-6 FAIL |
| NC-A2-cert | real (needs a group: N = 2) | a candidate node's new transmission inside a group → A2-5 FAIL |
| NC-A2-scalar | real (needs A2-8 PASS) | Simu5G `harqErrorRateDl:mean` perturbed → A2-8 FAIL |
| PC-A2-censor | real | log and grants cut mid-run at a TTI boundary → no FAIL, units in flight censored |
| PC-A2-inject | real + **injected NACK chain (synthetic)** | NACK → retransmission (scheduler lines naming the UE) → ACK on a clean PDU of the sparsest UE, gNB and UE side → A2-0…A2-4, A2-6, A2-7 PASS, one identified retransmission |
| NC-A2-nackid | injected | NACK unit line removed → A2-1 FAIL |
| NC-A2-nackswap | injected | the NACK names another PDU → A2-1 FAIL |
| NC-A2-rtxacid | injected | the scheduler names the other UE → A2-4 FAIL |
| NC-A2-rtxextract | injected | the retransmission line removed → A2-1 or A2-2 FAIL |
| NC-A2-discard | injected | the NACK turned into a discard after 1 transmission → A2-2 FAIL |

**The injection** needs a PDU whose (UE, process) is not reused before the chain's final ACK, so that the injected log is one Simu5G could produce. It is not buildable where the UE reuses its process too soon: predicted on N = 1, where UE 0 transmits in every TTI. In that case it is reported NOT BUILDABLE.

## 9. Limitations

1. No Simu5G-emitted NACK / retransmission / discard has ever been observed (§4, class 3). The generator and the injection encode this reading of the source.
2. The exchangeability certificate is checked against inserts only, since extracts do not change occupancy. Every exchangeable group's per-UE outcome is invariant by construction (design §5.6).
3. The end-of-run censoring rules are A-2's own definitions (§2). They are not accepted rules elsewhere.
4. Codeword ≠ 0 is handled by A-2 but not by the UE-side reference (A2-7 NOT EVALUATED).
5. MIMO codeword merging, handover and D2D are out of scope and fail closed.
6. UL is not covered.
7. The eventlog reader is deferred (R-7).
