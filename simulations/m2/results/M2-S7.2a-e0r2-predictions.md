## 2. Definition of PC-q8-lost-r2 (`check_m2s72_e0.mac_pdu_target`, `controls_r2`)

**Run.** `M2S72-E0-q0-f1`, seed 0 (Q-0, so gPTP and load share DRB 1). Existing raw outputs and MAC log only.

**Target selection.** Delivered single-segment Syncs, nearest the middle of the run first. A candidate is accepted only if **all** of the following hold, verified from the evidence:

| # | Condition |
|---|---|
| a | The MAC log has exactly one DL MAC PDU in that TTI. It is UE 0's (HARQ insert, node 2049), not deleted, and has a pid |
| b | Every gNB RLC PDU sent in that TTI (all entities of all UEs, `sentPduSize`) belongs to UE 0 on the gPTP DRB |
| c | The number of those RLC PDUs equals the MAC PDU's SDU count, and the MAC PDU bytes ≥ the RLC PDU bytes |
| d | Every one of those RLC PDUs has a matched UE RLC reception (same greedy rule as `gate_m2s71_p0.pdu_receptions`) |
| e | Every SDU owning one of them was delivered |

The selection does **not** assume that the TTI contains only one gPTP SDU.

**Composition** (inspected before this file; the mutation's outcome was not evaluated):

| Item | Value |
|---|---|
| Target | Sync 47, TTI 6000 ms |
| MAC PDU | 5845 B, 7 SDUs, HARQ process 5 |
| RLC PDUs | 7 on DRB 1: 11, 63, 93, 1413, 1421, 1421, 1421 B (total 5843 B) |
| Affected SDUs | 7: Sync 47 (62 B), Follow_Up 47 (92 B), and five 1420 B load SDUs (one ends with its 11 B tail segment, one begins with its 1413 B first segment) |
| gPTP keys affected | (Sync, 47) and (Follow_Up, 47) |
| Rejected candidates | none |

**Mutation.** Every observation consumed by Q8 / Q8-x is changed consistently. Nothing else is changed.

| Evidence | Change |
|---|---|
| MAC log | That MAC PDU is marked deleted, with no HARQ process and no pid (a deleted PDU is never inserted). Its process's next feedback within 10 ms is removed |
| UE RLC receptions | The 7 matched RX PDUs are removed (vector) |
| UE RLC deliveries | The 7 SDUs' deliveries are removed (vector and MAC-log RLC RX lines) |
| gPTP downstream | (Sync, 47) and (Follow_Up, 47) are removed from UE tx, DS-TT rx, DS-TT tx and slave rx, and from the slave frames used by the pair rule |
| Unchanged | Segments of the two partly affected load SDUs carried in **other** TTIs stay received, as they would in reality (the RLC cannot reassemble those SDUs). The gNB RLC TX side is unchanged, because a real deletion happens below the RLC |

**Not inputs of Q8 / Q8-x, so left untouched and disclosed:**
- application-level reception of the load SDUs (talker[0] ingress log);
- the DS-TT 0 log rows of seq 47, which Q8 reads only for frames that reached the DS-TT.
