## 2. Revised experimental design (deliverable 2)

**Common to every experiment:**
- M2S72Bridge; one gNB; DL gPTP; static roles; 12 s runs; D-4 timing; C-a clocks unless stated;
- generated configurations only (regeneration check, T0);
- per-clock RNGs;
- predictions committed before each batch;
- correctness-gate failure, any Q8 "unexplained", any **SIM-ABORT** (§3, G-4) or a control missing its outcome: **stop the batch** and keep the evidence.

**Seed policy [P-5, revised by RD-3].**
1. **Paired seeds.** Every compared configuration uses the same seed set (0–4), so that comparisons are paired.
2. **Fixed minimum.** 5 seeds for every stochastic comparison: a hypothesis test across options, regimes, N or HARQ.
3. **Reduced replication** (1 seed) only for a group whose relevant random mechanisms are shown **inactive or equivalent**, by an RNG-draw audit:
   - per RNG stream, the number of draws and the module drawing;
   - a stream with draws that can affect timing or delivery keeps the group stochastic.

   A hash match between two seeds is recorded as supporting evidence only, never as proof.
4. **Two kinds of evidence, reported separately:**
   - **numerical repeatability:** the same seed rerun gives identical PCAP / per-frame log hashes, checked once per batch on one run;
   - **statistical confidence:** across-seed intervals for performance metrics, using the S7.1 interval rule [A].
5. Applies only to Stage 5 runs. E0v is seed 0 only for calibration (E0 [A]); the declared f_E1 verification runs (RD-2) use seeds 0–4.

## 4. Resource and storage budget (deliverable 4)

### 4.1 VM budget (≈ 14 GB free, used now by the independent validation)

- **No Stage 5 run starts until the validation has finished and its outputs are dealt with.**
- **Per-run start rule [P-2 (a)],** replacing the ≥ 20 GB batch-start rule for new Stage 5 runs only:
  - free ≥ 1.5 × the largest expected run of the batch, + paired-twin size, + 1 GB checker temporaries, + 2 GB margin.
  - E0v f8: 1.5 × 2.6 + 2.6 + 1 + 2 ≈ **9.5 GB**; E3 / E1: ≈ 5 GB.
  - Checked before every run, not only at batch start; a shortfall means STOP and nothing deleted.
- **Concurrency:** one simulation at a time (`JOBS=1`). The checker runs after the simulation, never alongside.
- **Peak occupancy by experiment:**

  | Experiment | Peak |
  |---|---|
  | E0v | ≈ 5.5 GB |
  | E3 | ≈ 2 GB |
  | E1 | ≈ 2.5 GB |
  | P0 twin | ≈ 1.2 GB |

  All fit in 14 GB with the margin above, one at a time.

### 4.2 Evidence tiers [P-2 (b)]

| Tier | Contents | Where | Size |
|---|---|---|---|
| **A, committed** | protocol, predictions, check outputs, per-run digests (metrics CSV rows, MAC-log digest, Q8 class counts), `runs.tsv` (config, seed, commit, regeneration hash, stack), the sha256 manifest of every raw file, `env*.txt`, deletion log | Git | ≈ 0.1–0.5 MB per run; ≈ 50–100 MB for the whole of Stage 5 |

- **Historical raw evidence on this machine** (E0 11.5 GB etc.) and every accepted record stay untouched.
